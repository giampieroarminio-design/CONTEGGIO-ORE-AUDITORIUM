# Settimana

Pulsante **Settimana** (da [[Turni]]). Mostra lun–dom con:
- striscia di 7 tessere colorate (stessi colori della scheda del giorno: rosso lavoro, blu previsto, arancione assenza, verde libero);
- elenco giorno per giorno con orari, sala, pulsanti Squadra/Evento, nome festività;
- riga di sintesi: «N giorni liberi: …» oppure invito a importare le convocazioni.

Navigazione settimana precedente/successiva/"Questa settimana". Dopo un import si apre sulla settimana del primo turno importato (`weekHint`).

Scopo pratico: **vedere i giorni liberi** per concordare assenze o disponibilità.
