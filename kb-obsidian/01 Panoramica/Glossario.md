# Glossario

| Termine | Significato |
|---|---|
| **Convocazione** | PDF settimanale con gli orari di tutta la squadra |
| **Turno** | Fascia inizio–fine in un giorno ([[Turni]]) |
| **Previsto** (`confirmed:false`) | Turno importato dal PDF, non ancora confermato: **non conta** nel saldo |
| **Confermato** | Turno che conta nel saldo |
| **ps / pe** | Inizio/fine *previsti* dal PDF; `start`/`end` sono gli orari effettivi |
| **Variazione** | Differenza effettivo − previsto ([[Variazioni]]) |
| **Prolunga / Anticipo** | Uscita dopo il previsto / ingresso prima del previsto |
| **Banca ore** | Saldo cumulato ore lavorate − ore da contratto |
| **Riporto** | Saldo banca ore dei mesi precedenti ([[Residuo di partenza]]) |
| **Cedolino** | Busta paga: fonte del residuo iniziale |
| **Assenza concordata** | Giorno libero/ferie/malattia/permesso/L.104 ([[Assenze]]) |
| **Sala** | Luogo/sala: 700 → Sala Petrassi, 1200 → Sala Sinopoli, 2800 → Sala Santa Cecilia, CDJ → Casa del Jazz |
| **Squadra** | Colleghi dello stesso evento, letti dal PDF ([[Squadra ed Evento]]) |
| **Evento** | Testo della cella Evento del PDF |
| **Facchini** | Categoria indicata solo come numero di persone |
| **Ruota dei giorni** | Selettore circolare dei giorni ([[Ruota dei giorni]]) |
| **Patrono** | 29 giugno, Santi Pietro e Paolo, festivo a Roma (opzionale) |
| **Barratura** | Nome/orario sbarrato nel PDF = turno annullato |
| **Casella** | Mailbox dedicata da cui l'app scarica i PDF ([[Verifica aggiornamenti (casella)]]) |
| **MacroDroid** | App Android per automazioni: apre i link `?azione=` ([[Azioni rapide e link]]) |
